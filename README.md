# 📘 Практическое руководство по 1С:Предприятие 8 — учебный проект

## 📌 О проекте

Этот репозиторий — мои учебные наработки по мере прохождения книги
**«1С:Предприятие 8.3. Практическое пособие разработчика»** (Радченко, Хрусталева).

Здесь я последовательно реализую сквозной учебный пример из книги: от создания
справочников и документов до проведения, движений по регистрам и построения
отчетов. Цель — получить практический опыт разработки на платформе 1С и
подтвердить его рабочим проектом при поиске позиции **стажера / джуна
1С-разработчика**.

## 🎯 Зачем этот репозиторий

- Зафиксировать прогресс прохождения книги в виде рабочей конфигурации.
- Показать на собеседовании **реальный проект**, а не только теорию.
- Отработать типовые задачи, с которыми сталкивается джун: метаданные, формы,
  проведение документов, запросы, СКД.
- Иметь историю коммитов как доказательство самостоятельной работы.

## 🧠 Чему я учусь в процессе

- Работа с метаданными: справочники, документы, регистры накопления и сведений.
- Программирование на встроенном языке: обработка событий форм, проведение
  документов.
- Язык запросов и **система компоновки данных (СКД)**.
- Разработка управляемых форм и командного интерфейса.
- Работа в **1C:EDT** (современная среда разработки).
